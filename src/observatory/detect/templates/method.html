Como o teste funciona

Um detector só merece confiança se a gente souber quando ele erra. Este é o passo a passo, para que qualquer pessoa possa refazer o teste.

1. Os vídeos

O conjunto tem {{ b.dataset.videos }} vídeos: {{ b.dataset.ai }} gerados por IA e {{ b.dataset.real }} reais, sendo {{ b.dataset.br }} brasileiros. O rótulo de cada um vem de uma regra que não depende de ninguém olhar o vídeo e achar:

  • IA: o próprio autor declara o gerador (Sora, Veo, Kling, Runway). Tutoriais, vídeos de reação e animação ficam de fora, para que todo frame seja gerado.
  • Real: publicado antes de 2022, quando nenhum modelo público gerava vídeo realista. Propagandas de carro e vídeos com muito efeito visual ficam de fora.
  • Brasil: pares de propósito. Reportagens falsas feitas com IA ao lado de telejornais locais reais; esquetes de igreja ao lado de cultos reais.

2. A mesma prova para todos

Cada vídeo é baixado uma vez, dividido em cenas, e um frame de cada cena é guardado (até 8 por vídeo). O vídeo é apagado. Todas as ferramentas recebem exatamente esses frames e mais nada: sem título, legenda ou hashtags, que entregariam a resposta.

Os detectores comerciais dão uma nota por frame; a nota do vídeo é a média em log-odds. Os modelos de visão recebem todos os frames de uma vez (ou em lotes, quando o provedor limita o número de imagens).

3. As métricas

  • Real chamado de IA: parcela dos vídeos reais com nota ≥ {{ (ai_threshold * 100) | int }}%. É o erro que prejudica uma pessoa de verdade, então vem primeiro.
  • AUC: chance de um vídeo de IA qualquer receber nota maior que um real qualquer. 0,5 é cara ou coroa; 1,0 é perfeito.
  • IA detectada / IA chamada de real: parcela dos vídeos de IA com nota ≥ {{ (ai_threshold * 100) | int }}% / ≤ {{ (human_threshold * 100) | int }}%.
  • Inconclusivo: notas entre {{ (human_threshold * 100) | int }}% e {{ (ai_threshold * 100) | int }}%. Dizer "não sei" é melhor que errar.
  • Erro de calibração: se a ferramenta diz 80%, ela acerta 80% das vezes? Quanto menor, melhor.

4. Limites

  • O conjunto ainda é pequeno; diferenças de poucos pontos são ruído.
  • Vídeos reais tendem a ser mais antigos e de menor resolução. Uma ferramenta pode acertar por isso, e não por detectar IA. O relatório separa por resolução para medir esse efeito.
  • Frames isolados não mostram movimento. Alguns detectores comerciais analisam o vídeo inteiro e podem ir melhor fora deste teste.

How the test works

A detector only deserves trust if we know when it fails. This is the procedure, so anyone can re-run it.

1. The videos

The set has {{ b.dataset.videos }} videos: {{ b.dataset.ai }} AI-generated and {{ b.dataset.real }} real, {{ b.dataset.br }} of them Brazilian. Each label comes from a rule, not from someone eyeballing the video:

  • AI: the uploader names the generator (Sora, Veo, Kling, Runway). Tutorials, reactions and animation are excluded so every frame is generated.
  • Real: uploaded before 2022, when no public model could generate realistic video. Car ads and VFX-heavy clips are excluded.
  • Brazil: paired on purpose. AI-made fake TV reports next to real local news; church sketches next to real services.

2. Same exam for everyone

Each video is downloaded once, split into scenes, and one frame per scene is kept (up to 8). The video is deleted. Every tool receives exactly those frames and nothing else: no title, caption or hashtags, which would give the answer away.

Commercial detectors score each frame; the video score is the mean in log-odds. Vision models get all frames at once (or in batches where the provider caps images per request).

3. The metrics

  • Real called AI: share of real videos scored ≥ {{ (ai_threshold * 100) | int }}%. The error that harms a real person, so it comes first.
  • AUC: chance that a random AI video scores above a random real one. 0.5 is a coin flip; 1.0 is perfect.
  • AI caught / AI called real: share of AI videos scored ≥ {{ (ai_threshold * 100) | int }}% / ≤ {{ (human_threshold * 100) | int }}%.
  • Inconclusive: scores between {{ (human_threshold * 100) | int }}% and {{ (ai_threshold * 100) | int }}%. Saying "don't know" beats being wrong.
  • Calibration error: when a tool says 80%, is it right 80% of the time? Lower is better.

4. Limits

  • The set is still small; a few points of difference is noise.
  • Real videos skew older and lower resolution. A tool can be right because of that rather than because it detects AI. The report splits by resolution to measure the effect.
  • Isolated frames show no motion. Some commercial detectors analyze the whole video and may do better outside this test.
